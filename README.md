# Area-Level Social Disadvantage and Geographic Access to the Dental Workforce in the United States

Analysis code for a national cross-sectional study of dental workforce availability across
26,285 U.S. ZIP Code Tabulation Areas (ZCTAs).

## What this repository contains

R scripts that reproduce every number, table, and figure in the manuscript, from raw public
data files to final outputs. No raw data are redistributed here (see *Data availability*).

## Reproduction order

Run `run_all.R`, or execute scripts in numerical order. Each script writes its outputs to
disk and later scripts read them, so order matters.

| Order | Script | Produces |
|---|--------|----------|
| 1 | `Script1_National_US_Dentist_Extraction.R` | Dentist file from NPPES (14 dental taxonomy codes) |
| 2 | `Script2_National_FourWay_Merge.R` | Analytic sample: providers + SDI + population + RUCA |
| 3 | `Script2b_National_ADI_Construction.R` | ZCTA-level ADI via GeoCorr block-group crosswalk |
| 4 | `Script3_National_Models.R` | Within-ZCTA models (Table 3 top row; state gradients; index concordance) |
| 5 | `Script5_Catchment_Models.R` | Catchment supply, gradient table (Table 3), dental deserts |
| 6 | `Script8_Specialist_Catchment.R` | Specialist analyses (Table 2; Figure 3 inputs) |
| 7 | `Script10_UrbanRural_Descriptives.R` | Urban–rural descriptives at 15 miles |
| 8 | `Script12_SVI_Theme_Decomposition.R` | SVI theme models (Table 4; Supplementary Table S5) |
| 9 | `Script13_v2_State_Correlates.R` | State-level correlations (Supplementary Table S6) |
| 10 | `Script7_ADI_Main_Figures.R` | Figure 1; Figure 2 |
| 11 | `Script11_v5_Figure3_Harmonized.R` | Figure 3 |
| 12 | `Script14_v2_Figure4_TwoPanel.R` | Figure 4 |
| 13 | `Script15_STROBE_Flow_fixed.R` | Figure S1 (STROBE sample selection) |

Three further scripts (`Script4_National_Figures.R`, `Script6_Medicaid_Moderation.R`,
`Script9_State_Policy_Section.R`) document analyses that were conducted but whose results are
not reported in the final manuscript; see `MANIFEST.md`.

## Setup

1. Install R (>= 4.5.0) and the packages listed in `sessionInfo.txt`.
2. Download the input data files (below) into the paths named at the top of each script.
3. Edit `base_dir` in `config.R` to point to your project folder.

## Data availability

All input data are publicly available, but **licensing prevents redistribution of two
sources**, so no raw data files are included in this repository.

| Source | Access | Redistributable here? |
|--------|--------|----------------------|
| NPPES Full Replacement File (July 2026) | CMS, open download | Yes, but too large; download directly |
| ACS 2020–2024 5-year, table B01003 | data.census.gov | Public domain |
| 2020 RUCA ZIP code file | USDA ERS | Public domain |
| 2025 Census Gazetteer (ZCTA) | census.gov | Public domain |
| Social Deprivation Index, 2019 ZCTA | Robert Graham Center | Free with attribution |
| CDC/ATSDR SVI 2022 (ZCTA) | atsdr.cdc.gov | Public domain |
| Area Deprivation Index v4.0.1 | Neighborhood Atlas (free registration) | **No** — download under their terms |
| GeoCorr 2022 crosswalk | Missouri Census Data Center | Generated by user; settings documented in script 03 |
| ADA HPI data tables | ada.org | **No** — copyrighted by the ADA |

Derived outputs (model results, tables) are archived with the Zenodo release.

## Notes on reproducibility

- Catchment construction uses fixed-radius neighbor search on unit-sphere coordinates;
  results are deterministic.
- Mixed models are fitted with `glmmTMB`; estimates are deterministic given the same data
  and package version. Record `sessionInfo()` if you re-run.
- GeoCorr exports are user-generated: script 03 documents the exact settings
  (source = 2020 block group; target = 2020 ZCTA; weight = 2020 population).
